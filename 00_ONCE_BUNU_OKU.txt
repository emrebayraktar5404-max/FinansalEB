FINANSALEB v0.2.0 - GITHUB GUNCELLEME PAKETI

Bu surum iki ana sorunu duzeltir:
1) Varlik formundaki Vazgec dugmesi artik calisir.
2) BIST/ABD/ETF sembolleri ile TEFAS fon kodlari APK icinden otomatik aranir;
   varlik adi, veri sembolu ve guncel fiyat doldurulur.

Bu ZIP dosyasini bilgisayarinizda cikartin.
Cikartilan klasorun ICINDEKI tum dosya ve klasorleri mevcut GitHub deponuza yukleyin.
Ayni yoldaki eski dosyalarin uzerine yazilmasina izin verin.

GitHub ana dizininde dogrudan sunlar gorunmelidir:

ZIP dosyasinin kendisini GitHub'a yuklemeyin.

Yukleme tamamlaninca GitHub Actions otomatik baslar.
